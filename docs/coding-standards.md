# Coding Standards

## General Guidelines
- Write clear, intention-revealing code.
- Keep functions and modules focused on a single responsibility.
- Prefer explicitness over clever abstractions.
- Use consistent naming, formatting, and structure across the codebase.

## Review Expectations
- Ensure code is understandable to other contributors.
- Keep changes scoped to the issue or feature being addressed.
- Add or update tests when behavior changes.
- Document unusual decisions or edge cases.
