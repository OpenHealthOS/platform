# Coding Principles

## Core Principles
- One responsibility per service.
- No shared databases across services.
- Contracts are versioned.
- Events are immutable.
- APIs are backward compatible where practical.
- AI providers are interchangeable.
- Security is a default expectation.
- Observability is built in.
- Documentation accompanies every feature.

## Expected Impact
These principles help keep the platform understandable, maintainable, and aligned with the long-term architecture goals.
